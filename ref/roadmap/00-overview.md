# Roadmap Overview

> A self-paced study guide covering the modern backend / microservice / DevOps toolbox. Each file groups related technologies by purpose, lists the most popular choice first, and rates alternatives so you can pick what to learn next.

---

## Popularity Rating Legend

- **10/10** — Industry default. Knowing it is essentially required.
- **8–9/10** — Very common. A strong choice in most companies.
- **6–7/10** — Common in specific niches or at scale.
- **4–5/10** — Niche, older, or losing ground but still in use.
- **1–3/10** — Rare, legacy, new/experimental, or very specialized.

Ratings reflect **2025–2026 industry usage** based on job postings, surveys (Stack Overflow, JetBrains, CNCF), and ecosystem adoption.

## How to Use This Roadmap

1. Open the file for the category you want to learn.
2. The **#1 ranked tool** in each file is the default — start there.
3. Skim the alternatives so you understand trade-offs in interviews.
4. Pick **one alternative** to learn after the default if you have time (e.g., Postgres after MySQL).
5. Beginner / intermediate / advanced tags tell you when to invest time.
